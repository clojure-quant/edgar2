The depositary banks publish the ratios. The SEC tag does not.

Citi’s unsponsored DR directory is a table with ticker, CUSIP, and ratio: depositaryreceipts.citi.com. The column is ORD:DR, so 4:1 means four ordinary shares per one receipt. Examples on that page: ALSYY 4:1, CHEOY 1:2, BCHEY 20:1. That page is unsponsored programs only, so sponsored names such as BABA and TSM are not on it.

BNY’s directory is at adrbny.com. It covers programs at BNY, Citi, J.P. Morgan, and Deutsche Bank, searched by issuer or country. BNY writes the ratio the other way, DR:ORD. A BNY line of 1 : 2 is the same thing as Citi’s 2:1.

J.P. Morgan keeps the same kind of directory at adr.com. Sponsored programs are looked up one ticker at a time on whichever bank is the depositary.

There is no single free file of every sponsored ADR ratio. The Citi unsponsored table is the only bulk list that came back as a straight table.
